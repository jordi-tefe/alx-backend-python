# Unittests and Integration Tests

This project demonstrates the use of unit and integration testing in Python using the `unittest` framework, `mock`, and `parameterized`.

## What’s Covered

- Unit testing with edge cases and standard inputs
- Mocking external calls like HTTP requests
- Parametrizing test cases
- Memoization testing
- Integration testing using fixtures

## Tools Used

- Python 3.7
- unittest
- unittest.mock
- parameterized
